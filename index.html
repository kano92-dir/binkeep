Reverse engineering in the browser

binkeep is a web-based reverse engineering tool for the first look at an unknown binary. It parses Windows PE files (.exe, .dll, .sys), Linux ELF files (.so and executables) and macOS Mach-O files (including universal binaries) directly in the page, with no install and no upload.

It finds functions with a full linear sweep, builds cross-references for calls, jumps, imports and strings, and disassembles x86, x64, ARM and ARM64 code with Capstone compiled to WebAssembly. Real libyara runs your YARA rules locally. It also detects packers such as UPX, Themida and VMProtect, and recomputes Authenticode digests to show whether a signed file was modified.

It also reads .NET assemblies (types, methods, framework calls, user strings), Android APK and DEX files (manifest, permissions, components, classes) and ZIP archives, including password-protected malware samples. A capabilities view lists what a file can do, such as keylogging, persistence or process injection, mapped to MITRE ATT&CK techniques.

It is free and open source, works offline once loaded, and is built for malware triage, CTF challenges and quick checks before you reach for Ghidra or IDA.
